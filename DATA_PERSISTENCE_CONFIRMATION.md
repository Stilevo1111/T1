✅ **Длина фиссуры** - сохраняется в поле `fissure`
✅ **Время последнего использования** - сохраняется в поле `last_fissure`
✅ **Информация о пользователе** - сохраняется в поле `telegram_id` и `username`

### Как работает сохранение:

1. **При первом использовании**:
   - Создается запись в базе данных для пользователя
   - Устанавливается начальная длина фиссуры (0.1 см)
   - Устанавливается время последнего использования (0)

2. **При использовании команды `/fissure`**:
   - Обновляется длина фиссуры (увеличивается или уменьшается)
   - Обновляется время последнего использования (устанавливается текущее время)

3. **При проверке перезарядки**:
   - Сравнивается текущее время с `last_fissure`
   - Если прошло менее 24 часов (86400 секунд) - фиссура в перезарядке
   - Если прошло более 24 часов - можно использовать фиссуру

4. **При перезапуске бота**:
   - Данные автоматически загружаются из базы данных
   - Все результаты фиссуры и таймеры перезарядки сохраняются
   - Пользователи не теряют свои достижения

### Файл базы данных:

- **Имя файла**: `fissure_bot.db`
- **Тип**: SQLite
- **Размер**: 16384 байт (и будет расти по мере добавления пользователей)
- **Расположение**: в корневой директории проекта
