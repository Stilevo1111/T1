========================================
КОМАНДЫ ДЛЯ РУЧНОГО ДЕПЛОЯ
========================================

Скопируйте и выполните эти команды по порядку в терминале:

1. Перейти в папку проекта:
   cd c:\Users\akado\fissure-bot

2. Проверить статус (опционально):
   git status

3. Добавить файлы:
   git add requirements.txt runtime.txt bot.py

4. Создать коммит:
   git commit -m "Fix: replace aiogram with pyTelegramBotAPI"

5. Отправить в GitHub:
   git push origin main

========================================
ПРИМЕЧАНИЯ:
========================================

- Если команда "git" не найдена, установите Git:
  https://git-scm.com/download/win

- Если будет ошибка "not a git repository", выполните:
  git init
  git remote add origin https://github.com/hidlor/fissure-bot.git

- Если будет ошибка авторизации, настройте доступ:
  git config --global user.name "Ваше имя"
  git config --global user.email "ваш@email.com"
