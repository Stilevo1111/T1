# Fissure Bot

Telegram бот для игры "Фиссура" - развлекательный бот, где пользователи могут "увеличивать" свою фиссуру с помощью рандомных бросков.

## Особенности

- 🎲 Рандомные броски с разными исходами от -5 до +10 см
- ⏰ Система кулдауна (24 часа между бросками)
- 🏆 Таблица лидеров
- 📱 Удобное меню с кнопками
- 🗑️ Автоматическое удаление сообщений через 30 секунд
- 🗄️ PostgreSQL база данных

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/fissure-bot.git
cd fissure-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения:
```bash
export BOT_TOKEN="ваш_токен_бота"
export DATABASE_URL="ваш_адрес_postgresql_базы_данных"
```

4. Запустите бота:
```bash
python main.py
```

## Переменные окружения

- `BOT_TOKEN` - Токен вашего Telegram бота (получите у @BotFather)
- `DATABASE_URL` - URL подключения к PostgreSQL базе данных

## Команды

- `/start` - Начать работу с ботом
- `/fissure` - Сделать бросок (аналогично кнопке "📈 Увеличить фиссуру")
- `/stats` - Показать текущую длину (аналогично кнопке "📏 Моя длина")
- `/top` - Показать топ пользователей (аналогично кнопке "🏆 Топ")

## Развертывание на Render

Проект уже настроен для развертывания на Render. Для этого:

1. Создайте учетную запись на [Render](https://render.com)
2. Создайте новое веб-сервисное приложение и подключите свой репозиторий
3. Установите переменные окружения `BOT_TOKEN` и `DATABASE_URL` в настройках сервиса
4. Render автоматически создаст PostgreSQL базу данных и развернет бота
