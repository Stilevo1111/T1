# Telegram Бот "Фиссура"

Забавный Telegram бот с игровой механикой "увеличения фиссуры" с рандомными бросками и системой прокачки.

## Особенности

- 🎲 Рандомные броски от -5 до +10 см
- ⏰ Система кулдауна 24 часа
- 🏆 Таблица лидеров
- 🧹 Автоматическое удаление сообщений через 30 секунд
- 🗄️ PostgreSQL база данных
- 🚀 Webhook режим для работы на Render
- 📱 Удобное меню с кнопками

## Быстрый старт

### Для тестирования (самый простой способ)

1. Убедитесь, что у вас установлен Python 3.8+
2. Запустите: `python start_bot.py`

Бот начнет работать локально с SQLite базой данных. Скрипт сам инициализирует базу данных и подскажет, что нужно для полноценной работы.

### Для тестирования (простой способ)

1. Убедитесь, что у вас установлен Python 3.8+
2. Запустите бота: `python main.py`

Бот начнет работать локально с SQLite базой данных. Вам не нужно настраивать базу данных или переменные окружения для тестирования.

### Для production (с базой данных)

1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` с настройками (используя `.env.example` как образец)
3. Запустите: `python main.py`

## Требования

- Python 3.8+
- Telegram Bot Token (для обоих вариантов)
- PostgreSQL база данных (только для production)

## Запуск

### Простой запуск (для тестирования)

1. Убедитесь, что у вас установлен Python 3.8+
2. Запустите бота: `python main.py`

Бот будет работать локально с SQLite базой данных.

### Для production (на Render)

1. Загрузите проект на GitHub
2. Подключите репозиторий к Render
3. Создайте веб-сервис с типом Python
4. Укажите команду запуска: `python main.py`
5. Добавьте переменные окружения в настройках сервиса:
   - `BOT_TOKEN` - токен вашего Telegram бота
   - `DATABASE_URL` - URL PostgreSQL базы данных
   - `WEBHOOK_URL` - URL для webhook
6. Укажите health check path: `/health`

## Команды бота

- `/start` - Начать работу с ботом
- `/fissure` - Сделать бросок для увеличения фиссуры
- `/stats` - Показать текущую длину
- `/top` - Показать топ пользователей

## Особенности реализации

### Система бросков
- Рандомный выбор из 8 вариантов: [-5, -3, -1, 0, 1, 3, 5, 10]
- Минимальная длина фиссуры: 0.1 см
- Разные тексты и фразы для каждого исхода

### Автоматическое удаление сообщений
- Сообщения удаляются через 30 секунд для чистоты чата
- Команды удаляются через 10 секунд
- Используются асинхронные задачи для планирования удаления

### База данных
- Поддержка PostgreSQL (рекомендуется для production)
- Поддержка SQLite (для тестирования)
- Автоматическое создание таблиц при первом запуске

### Webhook режим
- Оптимизирован для работы на Render
- Автоматическая настройка webhook URL
- Поддержка health check endpoint

## Развертывание на Render

1. Создайте аккаунт на [Render](https://render.com)
2. Подключите GitHub репозиторий
3. Создайте веб-сервис с типом Python
4. Укажите:
   - Start Command: `python main.py`
   - Region: oregon
   - Plan: free
5. Добавьте переменные окружения:
   - `BOT_TOKEN` - токен вашего Telegram бота
   - `DATABASE_URL` - URL PostgreSQL базы данных
   - `WEBHOOK_URL` - URL для webhook (например: https://fissure-bot.onrender.com/webhook)
6. Укажите health check path: `/health`
