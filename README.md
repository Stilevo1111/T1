# FISSURE Telegram Bot

Мемный Telegram-бот с RPG-элементами и PvP-сражениями.

## 🎮 Особенности

- 👤 Система персонажей с характеристиками
- 🌋 FISSURE - система случайных бонусов/штрафов
- ⚔️ PvP-сражения между игроками
- 👹 Боссы с уникальными способностями
- 🛒 Магазин с предметами (вдохновлен Dota 2)
- 🌟 Система талантов и уровней
- 🏆 Таблица лидеров
- 🧪 Зелья и регенерация HP

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- PostgreSQL база данных
- Telegram Bot Token

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/USERNAME/fissure-bot.git
cd fissure-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте окружение:
```bash
# Создайте файл .env на основе .env.example
cp .env.example .env

# Отредактируйте .env файл и добавьте:
BOT_TOKEN=your_bot_token_here
DATABASE_URL=postgresql://user:password@host:port/database
RENDER_EXTERNAL_URL=https://your-app.onrender.com
PORT=10000
```

4. Запустите бота:
```bash
python bot.py
```

## 📋 Команды

### Основные команды
- `/start` - Начать игру
- `/profile` - Просмотр профиля
- `/stats` - Статистика персонажа

### Боссы
- `/boss` - Информация о боссе
- `/attack` - Атаковать босса

### PvP
- `/pvp` - Список противников
- `/fight USER_ID` - Вызов на дуэль

### Магазин
- `/shop` - Открыть магазин
- `/buy ITEM` - Купить предмет
- `/potion TYPE` - Купить зелье
- `/heal` - Восстановить HP

### Система уровней и талантов
- `/talents` - Дерево талантов
- `/level_up` - Повысить уровень
- `/learn TALENT_ID` - Изучить талант
- `/stats_distribute POINTS` - Распределить характеристики

### FISSURE система
- `/fissure` - Ролл фиссуры
- `/fissure_top` - Топ по длине фиссуры

### Другое
- `/top` - Таблица лидеров
- `/achievements` - Достижения

## 🗄️ База данных

Проект использует PostgreSQL с асинхронным драйвером asyncpg.

### Схема базы данных

Основная таблица `users` содержит:
- Информацию о пользователе
- Характеристики персонажа
- Инвентарь и предметы
- Прогресс в игре
- Систему талантов
- PvP-статистику

## 🚀 Деплой на Render

1. Создайте новое Web Service на Render
2. Подключите репозиторий GitHub
3. Укажите команду запуска: `python bot.py`
4. Настройте переменные окружения в настройках сервиса
5. Render автоматически создаст PostgreSQL базу данных

## 🔧 Разработка

### Структура кода

Проект разделен на модули для лучшей поддержки:

- **handlers/** - Обработчики команд Telegram
- **database/** - Работа с базой данных
- **utils/** - Вспомогательные функции
- **game_logic.py** - Логика игры

### Добавление новых команд

1. Создайте функцию-обработчик в соответствующем модуле handlers/
2. Добавьте импорт в `handlers/__init__.py`
3. Зарегистрируйте обработчик в `bot.py`

### Добавление новых предметов

1. Добавьте предмет в `ITEMS` в `game_logic.py`
2. Укажите характеристики и стоимость
3. Предмет автоматически появится в магазине
