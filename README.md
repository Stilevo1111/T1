# Telegram Бот "Фиссура"

## Общее описание
**Fissure Bot** - это Telegram-бот для игрового чата, сочетающий элементы ролевой игры с системой прокачки персонажа и интеграцией с Dota 2. Основная механика - "фиссура" (аналог персонажа), которую пользователи могут увеличивать с помощью ежедневных бросков.

## Основные функции

### 🎲 Система фиссуры
- **Ежедневные броски** (раз в 24 часа) с рандомизированным результатом
- **Разные исходы**: от -10 см (фатальный урон) до +50 см (максимальный бонус)
- **Система стриков**: подряд идущие положительные результаты
- **Защита для маленьких фиссур**: уменьшение урона для новых игроков
- **Выходные бонусы**: повышенные шансы на успех по субботам и воскресеньям

### 🏆 Соревновательные системы
- **Топ фиссур**: ежедневный рейтинг по размеру фиссуры
- **Топ MMR**: рейтинг игроков Dota 2 по рейтингу
- **Недельные дайджесты**: статистика за неделю с прорывами и рекордами
- **Система позиций**: автоматическое обновление мест в рейтингах

### 🎮 Dota 2 интеграция
- **Привязка Steam аккаунта** по SteamID, ссылке на Dotabuff или никнейму
- **Автоматическое обновление MMR** каждый час
- **Недельная статистика**: винрейт, количество игр, стрики побед
- **Ранги и титулы**: от Рекрута до Титана с визуальными обозначениями
- **Поиск игроков** через OpenDota API

### 📊 Статистика и аналитика
- **Индивидуальная статистика**: общее количество бросков, рост, стрики
- **Недельная статистика**: игры, победы, винрейт за неделю
- **Дайджесты**: утренние (9:00 МСК) и чередующиеся (каждые 10 минут)
- **Ручные дайджесты**: команды для немедленного просмотра статистики

### 🤖 Автоматизация
- **Ежедневные задачи**: уменьшение фиссуры неактивным игрокам
- **Еженедельные задачи**: сброс статистики по понедельникам
- **Автоматическое обновление**: MMR всех привязанных игроков
- **Система кеша**: оптимизация производительности с записью в БД раз в сутки

### 🎯 Особенности
- **Работает в групповых чатах и личных сообщениях**
- **Поддержка PostgreSQL и SQLite**
- **Вебхук-режим для хостинга на Render**
- **Система приветствия новых участников**
- **Удаление сообщений для чистоты чата**
- **Кликабельные никнеймы в статистике**

## Команды
- `/fissure` - увеличить фиссуру
- `/stats` - моя статистика
- `/top` - топ фиссур
- `/topmmr` - топ MMR
- `/link [steam_id]` - привязать Steam (повторная привязка перезаписывает)
- `/refresh` - обновить MMR

## Автоматические функции
- **Ежедневные дайджесты** в чате (утренний + Dota, чередуются каждые 15 сек)
- **Еженедельный дайджест** по понедельникам
- **Поздравление победителя** топа MMR за неделю по понедельникам в 00:00 UTC
- **Уведомление о ранк-апе** при повышении ранга игрока
- **Автоматическая отвязка Steam** при выходе из чата

## Технологии
- **Python 3.10+**
- **python-telegram-bot v20+**
- **PostgreSQL/SQLite**
- **OpenDota API**
- **Aiohttp для вебхуков**
- **Alembic для миграций**

Бот идеально подходит для игровых сообществ, где участники могут соревноваться в прокачке своих "фиссур" и демонстрировать свои достижения в Dota 2.
