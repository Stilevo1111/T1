# Telegram Бот "Фиссура"

Забавный Telegram бот с игровой механикой "увеличения фиссуры" с рандомными бросками и системой прокачки.

## Особенности

- 🎲 Рандомные броски с системой защиты и бонусов
- 🛡️ Усиленная защита для маленьких фиссур
- 💀 Фатальные броски для больших фиссур
- ⏰ Система кулдауна 3 часа
- 🎉 **Бонус выходного дня** - увеличенные награды в субботу и воскресенье (x1.5-x2.5)
- 🏆 Таблица лидеров с медалями 🥇🥈🥉
- 📉 Ежедневное уменьшение fissure для неактивных игроков
- 🧹 Автоматическое удаление сообщений
- 👑 Кликабельные никнеймы - можно нажать для открытия профиля
- 📊 Подробная статистика: броски, стрик, текущая длина
- 📈 Утренний дайджест с лидерами роста и падения
- 🔥 Система стриков
- 🚀 Webhook режим для работы на Render
- 👋 Приветствие новых участников чата

## Быстрый старт

### Для тестирования (самый простой способ)

1. Убедитесь, что у вас установлен Python 3.8+
2. Запустите: `python start_bot.py`

Бот начнет работать локально с SQLite базой данных. Скрипт сам инициализирует базу данных и подскажет, что нужно для полноценной работы.

### Для production (с базой данных)

1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` с настройками (используя `.env.example` как образец)
3. Запустите: `python main.py`

## Требования

- Python 3.8+
- Telegram Bot Token (для обоих вариантов)
- PostgreSQL база данных (только для production)

## Запуск

### Простой запуск (для тестирования)

1. Убедитесь, что у вас установлен Python 3.8+
2. Запустите бота: `python main.py`

Бот будет работать локально с SQLite базой данных.

### Для production (на Render)

1. Загрузите проект на GitHub
2. Подключите репозиторий к Render
3. Создайте веб-сервис с типом Python
4. Укажите команду запуска: `python main.py`
5. Добавьте переменные окружения в настройках сервиса:
   - `BOT_TOKEN` - токен вашего Telegram бота
   - `DATABASE_URL` - URL PostgreSQL базы данных
   - `WEBHOOK_URL` - URL для webhook
6. Укажите health check path: `/health`

## Команды бота

- `/start` - Начать работу с ботом
- `/fissure` - Сделать бросок для увеличения фиссуры
- `/stats` - Показать текущую длину
- `/top` - Показать топ пользователей
- `/digestnow` - Запустить утренний дайджест вручную
- `/setdigestchat` - Установить текущий чат для получения дайджестов

Кнопки меню:
- 📈 Увеличить фиссуру - сделать бросок
- 📏 Моя длина - показать текущий размер
- 🏆 Топ - показать таблицу лидеров

## Система бросков

### Уровни защиты и бонусов

| Размер фиссуры | Механика | Шанс |
|----------------|----------|------|
| < 5 см | ✨ МАКСИМАЛЬНАЯ ПОМОЩЬ | 80% |
| 5-20 см | 🚀 УЛУЧШЕННЫЙ РОЛЛ | 40% |
| 20-100 см | 🍀 УДАЧНЫЙ РОЛЛ | 20% |
| 100+ см | 🍀 УДАЧНЫЙ РОЛЛ | 10% |

### Детали бонусов

**✨ МАКСИМАЛЬНАЯ ПОМОЩЬ** (для фиссур < 5 см):
- +5 см: 30%
- +10 см: 25%
- +20 см: 20%
- +30 см: 15%
- +50 см: 10%

**🚀 УЛУЧШЕННЫЙ РОЛЛ** (для фиссур 5-20 см):
- +3, +5, +10, +20 см (равные шансы)

**🍀 УДАЧНЫЙ РОЛЛ** (для фиссур 20+ см):
- +5, +10, +20 см (равные шансы)

### Обычный баланс (если не выпал бонус)

| Результат | Шанс |
|-----------|------|
| +20 см | 5% |
| +10 см | 15% |
| +5 см | 15% |
| +3 см | 15% |
| +1 см | 15% |
| 0 см | 5% |
| -1 см | 15% |
| -3 см | 15% |

**Итого:** Выигрыш 65%, Проигрыш 30%, Ничья 5%

### 💀 Фатальный урон

Для фиссур **≥ 20 см** существует шанс фатального уменьшения:
- Шанс: 2%
- Результат: критическое уменьшение

Маленькие фиссуры (< 20 см) защищены от фатального урона.

### 🎉 Бонус выходного дня

В **субботу и воскресенье** все положительные результаты умножаются:
- x1.5, x2 или x2.5 (рандомно)
- Показывается сообщение: "🎉 ВЫХОДНОЙ! x2.5"

**Пример:** обычный ролл +10 см в воскресенье может стать +15, +20 или +25 см

## Таблица лидеров

- Топ-10 игроков с наибольшей длиной fissure
- 🥇 Первое место - золотая медаль
- 🥈 Второе место - серебряная медаль  
- 🥉 Третье место - бронзовая медаль

## Ежедневное уменьшение fissure

Если игрок не играет более 1 дня, его fissure автоматически уменьшается:
- Минус 1 см за каждый день неактивности
- Минимальное значение: 0.1 см
- Проверка выполняется каждый день в полночь

## Автоматическое удаление сообщений

- Сообщения бота удаляются через **30 секунд** для чистоты чата
- Результаты отправляются как **reply** на сообщение пользователя
- Используется JobQueue для планирования удаления
- При нажатии кнопки меню старое сообщение бота удаляется мгновенно
- Приветствия удаляются через 1 час

## Система дайджестов

### Утренний дайджест

- Автоматическая отправка статистики в **9:00 утра**
- Показывает:
  - 📈 Игрок с максимальным ростом позиций
  - 💀 Игрок с максимальным падением см
  - 🍀 Игрок с текущим стриком побед
- Настраивается командой `/setdigestchat`

### Еженедельный дайджест

- Отправляется по **понедельникам** в 9:00 утра
- Показывает статистику за неделю
- Лучший игрок недели получает особую отметку

### Ручной запуск

- `/digestnow` - отправить дайджест в текущий чат немедленно
- `/setdigestchat` - установить чат для автоматических дайджестов

## Система стриков

- **current_streak** - текущее количество побед подряд
- **best_streak** - лучший стрик за всё время
- Стрик сбрасывается при проигрыше (отрицательный результат)
- Отображается в профиле и в дайджесте

## База данных

- Поддержка PostgreSQL (рекомендуется для production)
- Поддержка SQLite (для тестирования)
- Автоматическое создание таблиц при первом запуске
- Хранит: telegram_id, username, fissure, last_fissure, last_message_id, last_activity, current_streak, best_streak

## Webhook режим

- Оптимизирован для работы на Render
- Автоматическая настройка webhook URL
- Поддержка health check endpoint (/health)
- Встроенная wake-up система (каждые 14 минут)
- При добавлении бота в чат он автоматически устанавливает его как чат для дайджестов

## Приветствие новых участников

- Бот отправляет приветственное сообщение с кликабельным ником, когда пользователь вступает в чат
- Сообщение автоматически удаляется через 1 час

## Развертывание на Render

### Автоматическое развертывание (рекомендуется)

1. Создайте аккаунт на [Render](https://render.com)
2. Подключите GitHub репозиторий
3. Нажмите **New +** → **Web Service**
4. Выберите репозиторий с ботом
5. Укажите:
   - Name: fissure-bot
   - Region: oregon
   - Plan: free
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python main.py`
6. Добавьте переменные окружения:
   - `BOT_TOKEN` - токен вашего Telegram бота
   - `DATABASE_URL` - URL PostgreSQL базы данных (Render создаст автоматически)
   - `WEBHOOK_URL` - URL для webhook (https://fissure-bot.onrender.com/webhook)
7. Укажите health check path: `/health`

### Как избежать сна на Render (Free Tier)

Бесплатный план Render засыпает через **15 минут неактивности**.

**Решение:** Добавьте внешний пингер на https://cron-job.org:

1. Зарегистрируйтесь на https://cron-job.org
2. Создайте задачу:
   - Title: fissure-bot wake-up
   - URL: https://fissure-bot.onrender.com/health
   - Schedule: `*/10 * * * *` (каждые 10 минут)

Теперь бот не будет засыпать и будет отвечать мгновенно.
