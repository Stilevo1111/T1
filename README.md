# Telegram Бот "Фиссура"

## Общее описание
**Fissure Bot** — Telegram-бот для игрового чата, сочетающий элементы ролевой игры с системой прокачки персонажа и интеграцией с Dota 2. Основная механика — "фиссура" (аналог персонажа), которую пользователи могут увеличивать с помощью ежедневных бросков.

## Команды
- `/start` — запустить бота и показать меню
- `/fissure` — увеличить фиссуру (раз в 24 часа)
- `/stats` — моя статистика
- `/top` — топ фиссур
- `/topmmr` — топ MMR за неделю
- `/link [steam_id]` — привязать Steam (повторная привязка перезаписывает)
- `/refresh` — обновить MMR вручную

## Основные функции

### 🎲 Система фиссуры
- **Ежедневные броски** (раз в 24 часа) с рандомизированным результатом
- **Разные исходы**: от -10 см (фатальный урон) до +50 см (максимальный бонус)
- **Система стриков**: подряд идущие положительные результаты
- **Защита для маленьких фиссур**: уменьшение урона для новых игроков
- **Выходные бонусы**: x1.5–x2.5 к положительным броскам по субботам и воскресеньям (по МСК)

### 🏆 Соревновательные системы
- **Топ фиссур**: ежедневный рейтинг по размеру фиссуры
- **Топ MMR**: рейтинг игроков Dota 2 с винрейтом, стриками и рангом
- **Победитель недели**: поздравление игрока с лучшим результатом в топе MMR (каждый понедельник)
- **Недельные дайджесты**: статистика за неделю с прорывами и рекордами
- **Система позиций**: автоматическое обновление мест в рейтингах

### 🎮 Dota 2 интеграция
- **Привязка Steam аккаунта** по SteamID, ссылке на Dotabuff или никнейму
- **Автоматическое обновление MMR** каждый час
- **Недельная статистика**: винрейт, количество игр, стрики побед
- **Ранги и титулы**: от Рекрута до Титана с визуальными обозначениями
- **Уведомление о ранк-апе**: сообщение в чат при повышении ранга игрока
- **Поиск игроков** через OpenDota API

### 📊 Дайджесты и статистика
- **Утренний дайджест** — позиция фиссуры, рост за день, топ приростов
- **Dota дайджест** — MMR, ранг, винрейт, топ за неделю
- **Чередование** каждые 15 секунд (закреплённое сообщение в чате)
- **Еженедельный дайджест** по понедельникам — топ за неделю, прорывы, позиции
- **Индивидуальная статистика**: броски, рост, стрики, лучшие результаты

### 🤖 Автоматизация
- Уменьшение фиссуры неактивным игрокам (раз в сутки)
- Сброс недельной статистики по понедельникам
- Обновление MMR всех привязанных игроков (раз в час)
- Система кеша с записью в БД раз в сутки и при остановке бота
- Приветствие новых участников чата
- Автоматическая отвязка Steam при выходе пользователя из чата
- Удаление служебных сообщений для чистоты чата

### 🎯 Особенности
- Работает в групповых чатах и личных сообщениях
- Поддержка PostgreSQL и SQLite
- Вебхук-режим для хостинга на Render
- Кликабельные никнеймы в статистике

## Технологии

- **PostgreSQL / SQLite**
- **OpenDota API**
