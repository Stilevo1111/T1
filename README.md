# Telegram Бот "Фиссура"

**Fissure Bot** — Telegram-бот для игрового чата, сочетающий элементы ролевой игры с системой прокачки персонажа и интеграцией с Dota 2.

## Команды

### Основные
- `/start` — запустить бота и показать карточку профиля с меню
- `/fissure` или `/fissura` — бросить кости для увеличения фиссуры (раз в 24 часа)
- `/profile` — ваша статистика (броски, рост, стрики, лучшие результаты), можно посмотреть чужой профиль: `/profile @username`
- `/top` — топ игроков по размеру фиссуры
- `/topmmr` — топ MMR за неделю

### Dota 2
- `/link [steam_id|ссылка|никнейм]` — привязать Steam аккаунт
- `/analyze` — показать график IMP (Impact) за последние 10 матчей с аналитикой

### Дайджест
- `/digestnow` — запустить дайджест фиссуры в текущем чате
- `/dotadigestnow` — запустить Dota дайджест в текущем чате
- `/setdigestchat` — установить текущий чат для дайджестов

### Админские
- `/resetgame` — сброс игры (все фиссуры сбрасываются на 0)
- `/testgreeting` — тестовая команда для отправки утреннего и вечернего приветствия
- `/testmvp` — тестовая команда для отправки поздравления MVP недели

## Основные функции

### Система фиссуры
- **Ежедневные броски** — раз в 24 часа
- **Результаты**: от -10 см до +50 см
- **Стрики** — подряд идущие положительные результаты
- **Защита новичков** — уменьшенный урон для маленьких фиссур
- **Выходные бонусы** — x1.5–x2.5 по субботам и воскресеньям (МСК)

### Сбор фиссур (Бонусная система)
- При **10 коллективных бросках** все игроки получают бонус
- Бонус позволяет сделать бросок **без кулдауна**
- Срок действия: **5 часов** (затем истекает)
- Счётчик сбрасывается в полночь

### Соревновательные системы
- **Топ фиссур** — ежедневный рейтинг
- **Топ MMR** — недельный рейтинг Dota 2
- **Система позиций** — отслеживание места в топе

### Dota 2 интеграция
- Привязка по SteamID, ссылке на Dotabuff или никнейму
- Автоматическое обновление MMR (каждый час)
- Недельная статистика: винрейт, игры, стрики побед
- Ранги: Рекрут → Титан
- Уведомление о ранк-апе в чате
- Поиск через OpenDota API
- **Герой мета** — анализ популярности героев по ролям
- **Аналитика IMP** — `/analyze` показывает график Impact за 10 последних матчей, кнопка "Статистика🧠" открывает детальную таблицу с KDA, GPM, XPM, данженсами

### Дайджесты
- **Фиссура дайджест** — обновляется каждые 15 секунд (закреплённое сообщение)
- Показывает: топ игроков, изменения позиций, стрики
- **Dota дайджест** — чередуется с фиссурой, показывает топ MMR
- **Герой мета баннер** — визуальная инфографика топ-5 героев по ролям с винрейтами, обновляется при создании нового поста дайджеста

### Автоматизация
- MMR: обновление каждый час
- Дайджест: обновление каждые 15 секунд
- Герой мета: обновление при создании нового поста дайджеста
- Приветствие новых участников
- Отвязка Steam при выходе из чата
- Удаление служебных сообщений

## Особенности
- Работает в группах и личных сообщениях
- Кликабельные никнеймы в статистике
- Визуальные баннеры с героями Dota 2
- Автоматические дайджесты с инфографикой
- PostgreSQL или SQLite
- Вебхук-режим для хостинга

## Технологии
- Python 3.13+
- python-telegram-bot v21.7
- PostgreSQL / SQLite
- OpenDota API
- Pillow (генерация изображений)
- aiohttp (вебхуки)
- alembic (миграции)
