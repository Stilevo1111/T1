# Fissure Bot — Telegram-бот для игрового чата

**Fissure Bot** — Telegram-бот, сочетающий ролевую игру с прокачкой персонажа и интеграцией с Dota 2.

## Команды

### Основные
- `/start` — показать карточку профиля с главным меню
- `/fissure` или `/fissura` — бросить кости для увеличения фиссуры (раз в 24 часа)
- `/profile` — ваша статистика (броски, рост, стрики), можно посмотреть чужой профиль: `/profile @username`
- `/top` — топ игроков по размеру фиссуры
- `/topmmr` — топ MMR за неделю

### Dota 2
- `/link [steam_id|ссылка|никнейм]` — привязать Steam аккаунт
- `/analyze` — график IMP (Impact) за последние 10 матчей с детальной статистикой

### Дайджест
- `/digestnow` — запустить дайджест фиссуры в текущем чате
- `/dotadigestnow` — запустить Dota дайджест в текущем чате

### Админские (только для создателей)
- `/resetgame` — сброс всех фиссур на 0
- `/setdigestchat` — установить текущий чат для автоматических дайджестов
- `/testgreeting` — тестовое утреннее/вечернее приветствие
- `/testmvp` — тестовое поздравление MVP недели

## Система фиссуры

- **Ежедневные броски** — раз в 24 часа (МСК)
- **Результаты**: от -10 см до +50 см
- **Стрики** — подряд идущие положительные результаты
- **Защита новичков** — уменьшенный урон для маленьких фиссур
- **Выходные бонусы** — x1.5–x2.5 по субботам и воскресеньям (МСК)

### Бонусная система
- При **10 коллективных бросках** все игроки получают возможность бросить без кулдауна
- Срок действия бонуса: **5 часов**
- Счётчик сбрасывается в полночь (МСК)

## Dota 2 интеграция

- Привязка по SteamID, ссылке на Dotabuff или никнейму
- Автоматическое обновление MMR (каждый час)
- Недельная статистика: винрейт, игры, стрики побед
- Ранги: Рекрут → Титан
- Уведомление о ранк-апе в чате
- Герой мета — топ-5 героев по ролям с винрейтами
- Аналитика IMP — график Impact за 10 последних матчей

## Дайджесты

- **Фиссура дайджест** — ежедневное обновление с топом игроков
- **Dota дайджест** — чередуется с фиссурой, показывает топ MMR
- **Герой мета баннер** — визуальная инфографика топ-5 героев по ролям

## Автоматизация

- MMR: обновление каждый час
- Дайджест: автоматическое обновление каждые 15 секунд
- Герой мета: обновление при создании нового поста дайджеста
- Утреннее приветствие в 09:00 (МСК)
- Вечернее приветствие в 23:00 (МСК)
- Чемпион недели объявляется в воскресенье 23:00 (МСК)
- Автоматическое удаление служебных сообщений
- Отвязка Steam при выходе из чата

## Технологии

- Python 3.13+
- python-telegram-bot v21.7
- PostgreSQL (основная БД) / SQLite (резервная)
- OpenDota API
- Pillow (генерация изображений)
- aiohttp (вебхуки)
