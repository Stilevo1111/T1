# Fissure Bot

**Fissure Bot** — Telegram-бот, сочетающий ролевую игру с прокачкой персонажа и интеграцией с Dota 2.

## Возможности

- 🎮 Мини-игра "Фиссура" с системой роста/падения
- 📊 Полная интеграция с OpenDota API
- 📈 Аналитика игроков (IMP, статистика)
- 🏆 Система MVP и ранк-апов
- 🕒 Автоматические дайджесты

## Команды

### Игровые
- `/start` — карточка профиля с главным меню
- `/fissure` (или `/fissura`) — бросить кости для увеличения фиссуры (1 раз в 24 часа)
- `/profile` — ваша статистика, `/profile @username` — чужой профиль

### Статистика
- `/stats` — топ игроков по фиссуре
- `/top` — топ фиссур (детали)
- `/topmmr` — топ MMR за неделю

### Dota 2
- `/link [steam_id|ссылка|ник]` — привязать Steam аккаунт
- `/analyze` — график Impact за 10 последних матчей
- `/party` — подбор игроков по близости MMR (до 8 игроков)
- Написание `пати` или `party` в чат также запускает подбор игроков (только текстовый триггер, не команда)

### Дайджест
- `/digestnow` — установить чат для дайджестов
- `/dotadigestnow` — запустить Dota дайджест

### Админские
- `/resetgame` — сброс всех фиссур
- `/testgreeting` — тест приветствий
- `/testmvp` — тест MVP поздравления

## Система фиссуры

| Диапазон | Описание |
|----------|----------|
| +1 ... +75 см | Положительный рост |
| -1 ... -15 см | Минус (падение) |
| -10 (FATAL) | Катастрофа -50% к всем |

**Особенности:**
- Кулдаун: 24 часа
- Защита новичков (< 5 см) от FATAL
- Выходные бонусы (Сб, Вс): x1.5–x2.5 множитель
- Мультикаст: шанс x2/x3/x4 (скрытая анимация слотов)

## Dota 2 интеграция

**Привязка:**
- SteamID (цифры)
- Ссылка на Dotabuff
- Никнейм Steam

**Автообновление MMR:** каждый час

**Ранги:** Рекрут → Страж → Рыцарь → Герой → Легенда → Властелин → Божество → Титан

**Герой мета:** топ-5 героев по ролям (CARRY/MID/OFFLANE/SUPPORT)

## Автоматизация

| Задача | Время (МСК) |
|--------|-------------|
| Утреннее приветствие | 09:00 |
| Вечернее приветствие | 23:00 |
| MVP объявление | Вс 23:30 |
| MMR обновление | Каждые 2 часа |
| Дайджест обновление | Каждые 30 мин |

### Переменные окружения

```env
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql://user:pass@host/db

# Авторизация (необязательно)
ALLOWED_CHAT_ID=123456789          # Один чат
ALLOWED_CHATS=123,456,789          # Список чатов через запятую

# Производительность (Neon Free оптимизация)
MMR_CONCURRENCY_LIMIT=5             # Макс одновременных запросов к OpenDota
```

**Авторизация:** если переменные не заданы — бот работает во всех чатах. Private чаты (отрицательный chat_id) разрешены всегда.

### Запуск

```bash
python main.py
```

Бот работает в режиме webhook на Render.com.
