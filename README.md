# Fissure Bot

Telegram бот для управления "фиссурой" с игровыми механиками и системой рейтинга.

## Особенности

- 🎲 Рандомные изменения длины фиссуры (от -5 до +10 см)
- ⏰ Система кулдауна (24 часа на одно изменение)
- 🏆 Таблица лидеров
- 📱 Удобное меню с кнопками
- 💬 Автоматическое удаление сообщений через 30 секунд
- 🎭 Многочисленные мемы и фразы

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` и добавьте токен бота:
```
BOT_TOKEN=ваш_токен_бота
```

3. Запустите бота:
```bash
python main.py
```

## Команды

- `/start` - Начать работу с ботом
- `/fissure` - Увеличить фиссуру
- `/stats` - Показать текущую длину
- `/top` - Показать топ пользователей

## Как играть

1. Используйте команду `/fissure` или кнопку "📈 Увеличить фиссуру"
2. Получите случайное изменение от -5 до +10 см
3. Ждите 24 часа до следующего изменения
4. Следите за своим местом в топе
