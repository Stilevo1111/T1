# FISSURE Telegram Bot

Простой мемный Telegram-бот с мини-играми:
- 👤 Профиль
- 🌋 FISSURE
- ⚔️ PvP
- 🎰 Слоты

## Установка

1. Клонируем репозиторий:
```bash
git clone https://github.com/USERNAME/fissure-bot.git
cd fissure-bot
```

2. Устанавливаем зависимости:
```bash
pip install -r requirements.txt
```

3. Создаем файл `.env` на основе `.env.example` и вставляем туда ваш токен от @BotFather:
```bash
cp .env.example .env
```

4. Запускаем бота:
```bash
python bot.py
```
