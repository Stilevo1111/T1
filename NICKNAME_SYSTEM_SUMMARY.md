# Система никнеймов для Fissure Bot

## Обзор

Добавлена полноценная система никнеймов для игроков, позволяющая персонализировать игровой опыт и улучшить взаимодействие между пользователями.

## Реализованные функции

### 1. Автоматическое создание никнеймов
- **Функция**: `get_user(uid)` автоматически создает никнейм для новых пользователей
- **Формат**: `Игрок_XXXX` где XXXX - последние 4 цифры ID пользователя
- **Пример**: `Игрок_1234`

### 2. Смена никнейма
- **Команда**: `/setnick_ НовыйНик`
- **Пример использования**: `/setnick_ Герой_2024`
- **Ограничения**:
  - Минимум 2 символа
  - Максимум 20 символов
  - Запрещены символы: `<`, `>`, `&`, `"`, `'`

### 3. Меню смены никнейма
- **Кнопка**: "🏷 Сменить никнейм" в главном меню
- **Функция**: Показывает текущий никнейм и инструкции по изменению
- **Интерфейс**: Интерактивное меню с подсказками

### 4. Интеграция с PvP системой
- **Отображение**: Никнеймы игроков показываются в PvP боях
- **Формат**: `Игрок (Никнейм): HP, урон`
- **Пример**: `👤 Вы (Герой_2024): 150 HP, 25 урон`

### 5. Отображение в профиле
- **Местоположение**: В начале профиля, сразу после заголовка
- **Формат**: `🏷 Никнейм: [текущий_никнейм]`

## Техническая реализация

### Хранение данных
```python
# Добавлено в структуру пользователя
"nickname": "Игрок_XXXX"  # Никнейм игрока
```

### Валидация никнеймов
```python
# Проверка длины
if len(new_nickname) > 20: return False
if len(new_nickname) < 2: return False

# Проверка недопустимых символов
invalid_chars = ["<", ">", "&", "\"", "'"]
```

### Обновление существующих пользователей
```python
# Автоматическое добавление поля для старых пользователей
if "nickname" not in users[uid]:
    users[uid]["nickname"] = f"Игрок_{uid[-4:]}"
```

## Команды и функции

### Команды
- `/setnick_ [никнейм]` - Установить новый никнейм
- `/setnick_` (пустая) - Показать подсказку по использованию

### Функции
- `change_nickname_menu(msg)` - Показать меню смены никнейма
- `set_nickname(msg)` - Обработать установку нового никнейма
- `set_nickname_empty(msg)` - Обработать пустую команду

## Преимущества системы

1. **Персонализация**: Игроки могут выразить свою индивидуальность
2. **Удобство**: Легко запоминающиеся имена вместо ID
3. **Интеграция**: Полная интеграция с существующими системами (PvP, профиль)
4. **Безопасность**: Валидация на недопустимые символы
5. **Гибкость**: Возможность изменения никнейма в любое время

## Совместимость

- **Полная обратная совместимость** с существующими пользователями
- **Автоматическое обновление** старых аккаунтов
- **Интеграция** с PvP системой для реальных игроков
- **Поддержка** всех существующих функций бота

## Заключение

Система никнеймов значительно улучшает пользовательский опыт, делая игру более персональной и удобной. Игроки могут легко узнавать друг друга в PvP боях, а система автоматически обрабатывает все аспекты управления никнеймами.
