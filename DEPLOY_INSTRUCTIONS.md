# Инструкция по деплою бота на Render.com

## Подготовка

1. **Создайте репозиторий на GitHub**
   - Загрузите все файлы бота в репозиторий
   - Убедитесь, что файлы `bot.py`, `items.py`, `bosses.py`, `database.py`, `requirements.txt` и `render.yaml` находятся в корне репозитория

2. **Получите токен Telegram бота**
   - Напишите @BotFather в Telegram
   - Используйте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Сохраните полученный токен

## Деплой на Render.com

1. **Зарегистрируйтесь на [Render.com](https://render.com)**
   - Создайте аккаунт (можно через GitHub)

2. **Подключите репозиторий**
   - В панели управления Render нажмите "New" → "Web Service"
   - Выберите свой репозиторий из GitHub
   - Нажмите "Connect"

3. **Настройте сервис**
   - **Name**: fissure-bot (или любое другое имя)
   - **Region**: выберите ближайший регион
   - **Branch**: main (или основная ветка вашего репозитория)

4. **Настройте переменные окружения**
   - В разделе "Environment" добавьте переменные:
     - `BOT_TOKEN`: ваш токен Telegram бота
     - `PORT`: 10000 (уже указан в render.yaml)

5. **Настройте команды**
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`

6. **Запустите деплой**
   - Нажмите "Create Web Service"
   - Render автоматически выполнит сборку и запуск

## Проверка работы

1. **После деплоя**
   - Render покажет URL вашего сервиса (например: `https://fissure-bot.onrender.com`)
   - Дождитесь успешного завершения деплоя

2. **Проверьте бота**
   - Найдите своего бота в Telegram по имени
   - Напишите `/start`
   - Бот должен ответить: "🔥 Бот запущен\nFISSURE — мем, ни на что не влияет 😏"

## Возможные проблемы

### 1. Ошибка "BOT_TOKEN not found"
- Убедитесь, что переменная `BOT_TOKEN` добавлена в Environment Variables
- Проверьте, что токен введен правильно, без лишних пробелов

### 2. Ошибка импорта модулей
- Убедитесь, что все файлы (`items.py`, `bosses.py`, `database.py`) находятся в корне репозитория
- Проверьте, что в `requirements.txt` указаны все необходимые зависимости

### 3. Бот не отвечает
- Проверьте логи в панели Render
   - В разделе "Logs" можно увидеть ошибки запуска
   - Частые причины: неправильный токен, ошибки в коде, проблемы с зависимостями

### 4. Render бесплатно, но с ограничениями
- Бесплатный тариф: 750 часов в месяц (бот "усыпляется" при бездействии)
- Для постоянной работы рекомендуется платный тариф ($7/мес)
