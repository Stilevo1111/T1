# Логика команд и интеграции Dota 2 в Fissure Bot

## Dota 2 Команды

### 1. `/link <ник или Steam ID>`
**Назначение:** Привязка Steam аккаунта к Telegram пользователю

**Логика работы:**
1. Проверяет аргументы команды
2. Определяет тип идентификатора:
   - Если аргумент состоит только из цифр → Steam ID
   - Иначе → никнейм игрока
3. Выполняет поиск через Stratz API:
   - Для Steam ID: прямой запрос по ID
   - Для никнейма: поиск по имени
4. Сохраняет данные в БД:
   - steam_id
   - steam_nickname
   - mmr
   - dota_total_games
   - dota_wins
5. Возвращает результат пользователю

**Примеры использования:**
```
/link Miracle
/link 76561198012345678
```

### 2. `/topmmr`
**Назначение:** Показать топ игроков по винрейту за неделю

**Логика работы:**
1. Обновляет MMR для всех пользователей с привязанными Steam аккаунтами
2. Получает статистику из БД:
   - week_games (игры за неделю)
   - week_wins (победы за неделю)
   - winrate (процент побед)
3. Формирует топ-10 по винрейту (минимум 10 игр)
4. Определяет позицию текущего пользователя
5. Форматирует вывод с медалями и статистикой

**Особенности:**
- Автоматически обновляет MMR из Stratz API
- Показывает W-L формат (победы-поражения)
- Сбрасывается каждое воскресенье

### 3. `/Ruiner`
**Назначение:** Найти случайного "руинера" в чате

**Логика работы:**
1. Получает последние 50 сообщений из чата
2. Собирает уникальных пользователей (исключая бота)
3. Выбирает случайного пользователя
4. Формирует кликабельное имя пользователя
5. Возвращает результат

## Dota 2 Интеграция

### Stratz API

**Используемые эндпоинты:**
- `GET /players/{identifier}` - поиск по нику или Steam ID
- `GET /players/{steam_id}` - получение полной статистики

**Получаемые данные:**
- steam_id - уникальный идентификатор Steam
- nickname - игровой никнейм
- mmr - рейтинг игрока
- total_games - общее количество игр
- wins - количество побед
- rank_tier - ранг (если доступен)

**Преимущества Stratz:**
- Бесплатный API без необходимости регистрации
- Не требует Steam Web API ключа
- Поддерживает поиск по нику
- Возвращает актуальные данные

### База данных Dota 2 поля

**Основные поля в таблице users:**
```sql
steam_id BIGINT -- Steam ID пользователя
steam_nickname VARCHAR(255) -- Игровой никнейм
mmr INTEGER DEFAULT 0 -- Рейтинг MMR
dota_total_games INTEGER DEFAULT 0 -- Общее количество игр
dota_wins INTEGER DEFAULT 0 -- Общее количество побед
week_games INTEGER DEFAULT 0 -- Игр за неделю
week_wins INTEGER DEFAULT 0 -- Побед за неделю
week_updated_at TIMESTAMP -- Время последнего обновления недельной статистики
mmr_updated_at TIMESTAMP -- Время последнего обновления MMR
```

### Еженедельная статистика

**Логика подсчета:**
1. При каждом броске фиссуры:
   - Если рост > 0: week_games += 1, week_wins += 1
   - Если рост ≤ 0: week_games += 1
2. Обновление времени week_updated_at
3. Сброс счетчиков каждое воскресенье

**Использование в топе:**
- Требуется минимум 10 игр за неделю для попадания в топ
- Сортировка по винрейту (wins/games * 100)
- При равном винрейте - по количеству игр

### Автоматическое обновление MMR

**Процесс обновления:**
1. При вызове `/topmmr`:
   - Получает список всех пользователей с steam_id
   - Для каждого пользователя вызывает Stratz API
   - Обновляет mmr, total_games, wins в БД
2. При вызове `/link`:
   - Сохраняет актуальные данные при привязке
3. При запросе статистики пользователя:
   - Проверяет наличие steam_id
   - При необходимости обновляет данные

### Функции модуля dota_mmr.py

**Основные функции:**

1. `search_player_by_nickname(nickname)` - поиск игрока по нику
2. `get_player_stats(steam_id)` - получение полной статистики
3. `update_user_mmr(telegram_id)` - обновление MMR пользователя
4. `register_steam(telegram_id, identifier)` - регистрация Steam аккаунта
5. `get_user_dota_stats(telegram_id)` - получение сохраненной статистики
6. `is_steam_linked(telegram_id)` - проверка привязки Steam

**Обработка ошибок:**
- Таймауты запросов (10 секунд)
- Обработка HTTP ошибок
- Логирование всех операций
- Возврат None при ошибках

### Интеграция с основным ботом

**В main.py добавлены:**
1. Импорт модуля dota_mmr
2. Команды для Dota 2 функций
3. Обновление статистики в профиле пользователя
4. Отображение MMR и ранга в команде /stats

### Безопасность и ограничения

**Ограничения:**
- Максимум 10 запросов в секунду к Stratz API
- Таймаут 10 секунд на каждый запрос
- Ограничение на количество игр для топа (10+)

**Безопасность:**
- Проверка формата Steam ID
- Валидация никнеймов
- Защита от SQL инъекций (параметризованные запросы)
- Логирование подозрительных действий
