# Быстрая настройка PostgreSQL на Render

Да, **Postgres** (PostgreSQL) - это именно то что нужно!

## Шаг 1: Создайте PostgreSQL базу данных

1. Откройте https://dashboard.render.com
2. Нажмите синюю кнопку **"New +"** (справа вверху)
3. Выберите **"PostgreSQL"**
4. Заполните форму:
   - **Name**: `fissure-bot-db` (или любое имя)
   - **Database**: оставьте как есть (автоматически)
   - **User**: оставьте как есть (автоматически)
   - **Region**: выберите ближайший к вам (например, Frankfurt для Европы)
   - **PostgreSQL Version**: оставьте последнюю версию
   - **Datadog API Key**: оставьте пустым
   - **Plan**: выберите **"Free"** (бесплатно)
5. Нажмите **"Create Database"**
6. Подождите 1-2 минуты пока база создастся

## Шаг 2: Скопируйте DATABASE_URL

1. После создания откроется страница базы данных
2. Найдите раздел **"Connections"**
3. Найдите строку **"Internal Database URL"**
4. Нажмите на иконку копирования (📋) справа от URL
5. URL будет выглядеть примерно так:
   ```
   postgresql://fissure_bot_user:xxxxxxxxxxxxx@dpg-xxxxx-a.frankfurt-postgres.render.com/fissure_bot_db
   ```

## Шаг 3: Добавьте DATABASE_URL в бота

1. Вернитесь на главную страницу Dashboard
2. Найдите ваш Web Service **"fissure-bot"**
3. Кликните на него
4. Перейдите на вкладку **"Environment"** (вверху)
5. Нажмите **"Add Environment Variable"**
6. Заполните:
   - **Key**: `DATABASE_URL` (точно так, заглавными)
   - **Value**: вставьте скопированный URL из шага 2
7. Нажмите **"Save Changes"** (внизу страницы)

## Шаг 4: Подождите перезапуска

Render автоматически перезапустит бота с новой переменной окружения.

1. Перейдите на вкладку **"Logs"**
2. Подождите 1-2 минуты
3. Вы должны увидеть:
   ```
   ✅ Подключено к PostgreSQL
   HTTP сервер запущен на порту 10000
   Бот запущен...
   ```

## Шаг 5: Проверьте

1. Откройте Telegram
2. Отправьте боту `/start`
3. Используйте бота (FISSURE, PvP, покупка предметов)
4. Данные теперь сохраняются в PostgreSQL!

## Проверка что работает

### Тест сохранения:
1. Используйте FISSURE или купите предмет
2. На Render: Settings → **Suspend Service**
3. Подождите 10 секунд
4. Settings → **Resume Service**
5. Проверьте бота - данные должны остаться!

## Важно

### Бесплатный план PostgreSQL:
- ✅ 256 MB хранилища
- ✅ Достаточно для тысяч пользователей
- ✅ Автоматические бэкапы
- ✅ Постоянное хранение

### Если база заполнится:
Render покажет предупреждение. Можно:
- Обновиться на платный план ($7/месяц за 1GB)
- Очистить старые данные
- Экспортировать и пересоздать базу

## Что если не работает?

### Проверьте логи:
1. Вкладка **Logs** на странице бота
2. Ищите строку "✅ Подключено к PostgreSQL"
3. Если видите "❌ Ошибка подключения" - проверьте DATABASE_URL

### Проверьте DATABASE_URL:
1. Environment → найдите DATABASE_URL
2. Убедитесь что URL начинается с `postgresql://`
3. Убедитесь что нет лишних пробелов

### Если ошибка "relation does not exist":
Это нормально при первом запуске. База автоматически создаст таблицу.

## Готово!

Теперь все данные игроков сохраняются постоянно в PostgreSQL и не будут сбрасываться при деплоях или перезапусках бота.
