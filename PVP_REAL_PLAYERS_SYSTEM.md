# Система PvP-боев между реальными игроками

## Обзор

Новая система PvP позволяет игрокам сражаться друг с другом в реальном времени. Это полноценная система поиска соперников, синхронизации боев и обработки результатов для обоих участников.

## Особенности системы

### 🔍 Поиск соперников
- **Очередь поиска**: Игроки добавляются в очередь и автоматически подбираются друг другу
- **Проверка лимитов**: Система проверяет дневные лимиты обоих игроков перед началом боя
- **Отмена поиска**: Игрок может отменить поиск командой `/pvp_cancel`

### ⚔️ Реальные бои
- **Синхронизация**: Оба игрока видят один и тот же лог боя в реальном времени
- **Пошаговая система**: Бои проходят пошагово с паузами между ходами
- **Характеристики**: Учитываются все характеристики игроков (сила, ловкость, интеллект, крит, уклонение, броня)
- **Предметы**: Эффекты артефактов влияют на боевые характеристики

### 💰 Экономика
- **Победа**: +40 MMR
- **Поражение**: -20 MMR
- **Ничья**: Без изменений MMR
- **Дневной лимит**: 3 боя в день

## Команды

### Основные команды
- `⚔️ PvP` - Открыть меню PvP
- `/pvp_bot` - Бой с ботом
- `/pvp_find` - Поиск реального игрока
- `/pvp_stats` - Статистика PvP
- `/pvp_cancel` - Отменить поиск соперника

### Механика поиска

1. **Добавление в очередь**: Игрок вводит `/pvp_find`, система проверяет лимиты и добавляет в очередь
2. **Подбор соперника**: Как только в очереди есть 2 игрока, система автоматически создает бой
3. **Начало боя**: Обоим игрокам приходит сообщение о найденном сопернике и характеристиках
4. **Симуляция боя**: Через 3 секунды начинается автоматическая симуляция боя
5. **Результаты**: Оба игрока получают результаты боя и изменения MMR

### Ключевые функции

#### `pvp_find(msg)`
- Проверяет лимиты игрока
- Добавляет игрока в очередь поиска
- Запускает подбор соперника

#### `start_pvp_battle(player1_id, player2_id)`
- Создает уникальный ID боя
- Проверяет лимиты обоих игроков
- Отправляет сообщения о начале боя
- Запускает симуляцию боя в отдельном потоке

#### `run_pvp_battle(battle_id, player1_id, player2_id)`
- Рассчитывает характеристики обоих игроков
- Запускает пошаговую симуляцию боя
- Отправляет лог боя обоим игрокам
- Обрабатывает результаты и начисляет награды

## Пример работы системы

### Сценарий 1: Успешный поиск
1. Игрок 1 вводит `/pvp_find`
2. Игрок 2 вводит `/pvp_find` через 30 секунд
3. Система находит пару и создает бой
4. Обоим игрокам приходит сообщение:
   ```
   ⚔️ НАЙДЕН СОПЕРНИК!
   
   👤 Вы: 150 HP, 25 урон
   👤 Противник: 140 HP, 22 урон
   
   Бой начнется через 3 секунды...
   ```
5. Через 3 секунды начинается бой:
   ```
   ⚔️ PvP БОЙ НАЧАЛСЯ!
   
   👤 ИГРОК 1: 150 HP
   👤 ИГРОК 2: 140 HP
   
   Ход 1: ИГРОК 1 наносит 25 урона (ИГРОК 2: 115 HP)
          ИГРОК 2 наносит 20 урона (ИГРОК 1: 130 HP)
   ...
   🎉 ПОБЕДА ИГРОКА 1!
   ```
6. Результаты:
   - Игрок 1: +40 MMR, +1 победа
   - Игрок 2: -20 MMR, +1 поражение

### Сценарий 2: Отмена поиска
1. Игрок вводит `/pvp_find`
2. Ждет 2 минуты, решает отменить
3. Вводит `/pvp_cancel`
4. Получает сообщение: "❌ Поиск соперника отменен"

### Сценарий 3: Лимит боев
1. Игрок уже провел 3 боя сегодня
2. Вводит `/pvp_find`
3. Получает сообщение: "❌ Дневной лимит PvP исчерпан! (3 боя) 🔄 Сброс через X часов"

## Преимущества системы

1. **Реальное взаимодействие**: Игроки сражаются с реальными противниками
2. **Сбалансированная экономика**: Победа дает больше MMR, чем проигрыш забирает
3. **Ограничения**: Дневные лимиты предотвращают злоупотребление системой
4. **Прозрачность**: Оба игрока видят одинаковый лог боя
5. **Интеграция**: Система учитывает все характеристики и артефакты игроков
6. **Надежность**: Обработка ошибок и возврат игроков в очередь при проблемах

## Возможные улучшения

1. **Рейтинговая система**: Введение рейтинга для подбора равных по силе соперников
2. **Турниры**: Регулярные турниры с призами
3. **Наблюдение**: Возможность наблюдать за чужими боями
4. **Ставки**: Возможность делать ставки на исход боя
5. **Чат**: Общение между игроками до и после боя
6. **Реванш**: Возможность запросить реванш у того же противника

## Технические детали

- **Потоки**: Бои запускаются в отдельных потоках для независимой работы
- **Идемпотентность**: Система обрабатывает повторные команды и ошибки
- **Сохранение**: Все изменения сохраняются в базу данных после каждого боя
- **Временные метки**: Используются для сброса дневных лимитов
- **Уникальные ID**: Каждый бой имеет уникальный идентификатор

Система полностью готова к использованию и предоставляет игрокам возможность сражаться друг с другом в реальном времени!
