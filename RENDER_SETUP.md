# Настройка бота на Render

## Проблема
Бот не может найти `BOT_TOKEN` потому что файл `.env` не загружается на Render (он исключен через `.gitignore`, что правильно для безопасности).

## Решение: Установить переменные окружения на Render

### Подробные шаги:

#### Шаг 1: Откройте Dashboard Render
1. Перейдите на https://dashboard.render.com
2. Войдите в свой аккаунт

#### Шаг 2: Найдите ваш Web Service
1. На главной странице Dashboard вы увидите список всех ваших сервисов
2. Найдите сервис с именем **fissure-bot** (или как вы его назвали)
3. **Кликните на название сервиса** - откроется страница с деталями

#### Шаг 3: Откройте настройки Environment Variables
На странице вашего сервиса вы увидите несколько вкладок вверху:
- **Events** (события)
- **Logs** (логи)
- **Shell** (консоль)
- **Environment** ← **ВЫБЕРИТЕ ЭТУ ВКЛАДКУ**
- **Settings** (настройки)

Кликните на вкладку **"Environment"**

#### Шаг 4: Добавьте переменную BOT_TOKEN
1. На странице Environment вы увидите раздел **"Environment Variables"**
2. Нажмите синюю кнопку **"Add Environment Variable"**
3. Появятся два поля:
   - **Key** (ключ): введите `BOT_TOKEN` (точно так, заглавными буквами)
   - **Value** (значение): вставьте ваш токен от BotFather (например: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)
4. Нажмите кнопку **"Save Changes"** внизу страницы

#### Шаг 5: Дождитесь автоматического перезапуска
- После сохранения Render автоматически начнет **redeploy** (повторное развертывание)
- Вы увидите это в разделе **Events** или **Logs**
- Подождите 1-2 минуты
- Бот должен запуститься успешно

### Как получить токен бота:
1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте команду `/mybots`
4. Выберите вашего бота
5. Нажмите **"API Token"**
6. Скопируйте токен и вставьте в Render

### Проверка:
После добавления переменной окружения в логах Render вы должны увидеть:
```
Бот запущен...
```

Вместо:
```
Ошибка: BOT_TOKEN не найден в переменных окружения
```

## Важно:
- ❌ НЕ коммитьте файл `.env` в git
- ✅ Используйте `.env` только для локальной разработки
- ✅ На Render всегда используйте Environment Variables
- ✅ Токен бота должен оставаться секретным

## Локальная разработка:
Для локального запуска создайте файл `.env`:
```
BOT_TOKEN=ваш_токен_здесь
```

Этот файл автоматически игнорируется git'ом и не будет загружен на Render.
