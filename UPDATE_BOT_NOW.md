# Как обновить бота чтобы появились новые кнопки

Если новые кнопки не появились, нужно:

## Шаг 1: Проверьте деплой на Render

1. Откройте https://dashboard.render.com
2. Выберите ваш Web Service (fissure-bot)
3. Перейдите на вкладку **"Events"**
4. Посмотрите последнее событие:
   - Если "Deploy in progress" - подождите 2-3 минуты
   - Если "Deploy failed" - смотрите шаг 3
   - Если "Deploy succeeded" но давно - смотрите шаг 2

## Шаг 2: Принудительный деплой

Если последний деплой был давно (до добавления артефактов и боссов):

### Вариант A: Manual Deploy
1. На странице сервиса нажмите **"Manual Deploy"** (справа вверху)
2. Выберите **"Deploy latest commit"**
3. Подождите 2-3 минуты

### Вариант B: Suspend/Resume
1. Перейдите в **Settings**
2. Прокрутите вниз до "Danger Zone"
3. Нажмите **"Suspend Service"**
4. Подождите 10 секунд
5. Нажмите **"Resume Service"**

## Шаг 3: Проверьте логи на ошибки

1. Перейдите на вкладку **"Logs"**
2. Посмотрите последние сообщения
3. Должно быть:
   ```
   ✅ Подключено к PostgreSQL (или "Используется JSON файл")
   HTTP сервер запущен на порту 10000
   Бот запущен...
   ```

### Если есть ошибки:

#### Ошибка импорта items.py или bosses.py:
```
ModuleNotFoundError: No module named 'items'
```
**Решение**: Файлы не загрузились. Проверьте что они есть в репозитории:
```bash
git ls-files | grep -E "(items|bosses|database).py"
```
Должно вывести:
```
bosses.py
database.py
items.py
```

Если нет - закоммитьте снова:
```bash
git add items.py bosses.py database.py
git commit -m "Add missing files"
git push
```

#### Ошибка psycopg2:
```
ModuleNotFoundError: No module named 'psycopg2'
```
**Решение**: Проверьте requirements.txt:
```bash
cat requirements.txt
```
Должно быть:
```
pyTelegramBotAPI==4.14.0
python-dotenv>=1.0.0
requests>=2.31.0
psycopg2-binary>=2.9.9
```

## Шаг 4: Обновите клавиатуру в Telegram

После успешного деплоя:

1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте `/start` еще раз
4. Клавиатура должна обновиться

### Должны появиться кнопки:
- 👤 Профиль
- 🌋 FISSURE
- ⚔️ PvP
- 🎰 Слоты
- 👹 Рейд ← **НОВАЯ**
- 🎒 Инвентарь ← **НОВАЯ**
- 🏪 Магазин ← **НОВАЯ**

## Шаг 5: Проверьте функционал

### Тест магазина:
1. Нажмите 🏪 **Магазин**
2. Должно появиться меню с категориями
3. Отправьте `/weapons`
4. Должен показать список оружия

### Тест рейдов:
1. Нажмите 👹 **Рейд**
2. Должен показать список боссов
3. Отправьте `/raid_1`
4. Должен начаться бой с Roshan

### Тест инвентаря:
1. Нажмите 🎒 **Инвентарь**
2. Должно показать "Инвентарь пуст" (если ничего не куплено)

## Если ничего не помогло

### Проверьте версию кода на Render:

1. Вкладка **"Events"**
2. Найдите последний "Deploy succeeded"
3. Посмотрите commit hash (например: `072a99d`)
4. Сравните с локальным:
   ```bash
   git log --oneline -1
   ```

Если хеши не совпадают - Render использует старую версию.

### Принудительный push:
```bash
git commit --allow-empty -m "Force redeploy"
git push
```

Это создаст пустой коммит и заставит Render задеплоить.

## Время обновления

- **Автоматический деплой**: 2-3 минуты после push
- **Manual Deploy**: 2-3 минуты
- **Suspend/Resume**: 30-60 секунд

После любого метода подождите указанное время и проверьте бота в Telegram.

## Быстрая проверка

Отправьте боту любое сообщение. Если бот отвечает - он работает. Если не отвечает - проверьте логи на Render.
