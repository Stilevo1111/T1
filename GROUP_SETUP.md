# Настройка бота для работы в группах

## Шаг 1: Настройте бота в BotFather

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/mybots`
3. Выберите вашего бота
4. Нажмите **"Bot Settings"**
5. Нажмите **"Group Privacy"**
6. Выберите **"Turn off"** (отключить приватность)
   - Это позволит боту видеть все сообщения в группе
7. Вернитесь назад и нажмите **"Allow Groups?"**
8. Выберите **"Turn on"** (включить группы)

## Шаг 2: Добавьте бота в группу

1. Откройте вашу группу в Telegram
2. Нажмите на название группы → **"Add Members"**
3. Найдите вашего бота по username
4. Добавьте его в группу
5. (Опционально) Сделайте бота администратором если нужны дополнительные права

## Шаг 3: Протестируйте

В группе отправьте:
- `/start` - бот должен ответить
- Нажмите кнопки "👤 Профиль", "🌋 FISSURE" и т.д.

## Важные замечания:

### Приватность сообщений
- **Privacy Mode OFF** - бот видит ВСЕ сообщения в группе
- **Privacy Mode ON** - бот видит только команды и сообщения с упоминанием (@bot)

Для вашего бота лучше **OFF**, чтобы кнопки работали.

### Права администратора
Если хотите чтобы бот мог:
- Удалять сообщения
- Банить пользователей
- Изменять настройки группы

Нужно сделать его администратором:
1. Настройки группы → Administrators
2. Add Administrator → выберите бота
3. Настройте права

### Работа в каналах
Для работы в каналах:
1. Добавьте бота как администратора канала
2. Дайте права "Post Messages"
3. Бот сможет отправлять сообщения в канал
